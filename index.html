3 · 状态含义

判定方法：把该码点分别用「所选字体别名」与「一个必然不存在的字体名」各绘制一次，比较像素。 关键事实：同一个码点回退画两次是逐像素完全一致的（差异像素 = 0）， 所以出现可重复的非零差异，就说明这次确实用上了所选字体文件。

但「像素相同」不等于「该字体不覆盖」：也可能是该字体画出了与回退相同的形状，或者两边都没有墨迹。 因此本页把四件事分开：cmap 映射（解析自字体文件，与渲染无关）、 文件加载（能否被浏览器接受）、像素差异（差异像素数 / 是否可比）、 置信度（确定 / 语义 / 未能区分 / 无结论）。 像素与回退相同一律记为 未能区分，不下「不覆盖」也不下「空字形」的结论。

空白字符（U+0020 空格、U+3000 全角空格、U+00A0、零宽与控制字符等）在像素上天然没有分辨力， 按语义单独处理：只按 cmap 判定，完全不使用像素证据。cmap 里有该码点就记「空白字符·字体已定义」， 并注明进宽差作为旁证，绝不与前几种混算。 另有实测现象：个别带 CBDT/CBLC 位图表的字体，会在空格、制表符上画出一块可见的实心图形； 这属于源文件位图数据异常，会另标「空白位图异常」并计入汇总， 但仍不记为覆盖。 进宽差（px）只作为补充数据显示，不参与判定——空格等字符的进宽本来就可能与回退不同。 悬停色带可看到每个字符的 cmap / 加载 / 像素 / 置信度依据。

本地导入的字体另有一条纪律：若这份文件的 cmap 未能在浏览器内解析（例如 WOFF2 需要 Brotli 解压）， 映射维度一律记为「未解析」，此时的判定改用独立的三个判定码（本字体覆盖·映射未解析 / 空白字符·映射未解析 / 无可见字形·映射未解析）， 绝不套用页面自带清单里的码点数据来冒充这份文件。
